- [x] CONSTRAINT: Windows SSL proxy — antivirus intercepts HTTPS; `git push` requires `http.sslVerify=false` (already set locally). yt-dlp must use `--no-check-certificate`. Do NOT add any library that makes raw HTTPS calls without this bypass.
- [x] CONSTRAINT: Windows cp1252 encoding — yt-dlp subprocess must be launched with `PYTHONUTF8=1` in env or accented characters (é, í, ú) become `�`, breaking title matching.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| ytmsearch: prefix | `ytmsearch:` is NOT a valid yt-dlp URL scheme (tested, fails with "Unsupported url scheme"). Use `https://music.youtube.com/search?q=` URL instead. | blocking | Hard-coded URL pattern in `_search_yt_candidates` |
| spotDL / ytmusicapi | Both fail with SSL CERTIFICATE_VERIFY_FAILED on this machine (antivirus proxy). Do not add as dependencies. | blocking | Not in requirements.txt |
| Subprocess encoding | Running yt-dlp without `PYTHONUTF8=1` in env causes cp1252 output on Windows — accented chars corrupted | blocking | Env var set in `_search_yt_candidates` |
