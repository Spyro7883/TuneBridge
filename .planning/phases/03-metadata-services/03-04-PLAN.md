## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pasted URL → worker thread | Phase 2 classified URL strings cross from main thread (paste handler) into worker thread via `_executor.submit` arg-passing |
| Worker thread → main thread | Metadata dict crosses thread boundary via `Signal(int, object)` queued connection |
| Untrusted metadata fields → UI cell text | Spotify and YouTube responses become user-visible strings in column 0 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-15 | T (Tampering) | Malicious metadata field (e.g., extremely long string) injected into table cell | accept | QTableWidgetItem.setText handles arbitrary strings; column auto-resize already configured. No format-string vulnerability — f-strings interpolate values, not format codes |
| T-03-16 | I (Information disclosure) | Exception traceback containing token / URL secrets leaked into UI | mitigate | `_metadata_worker` catches `Exception` and emits only the literal string `"Failed — metadata"` — no exception details surface to UI |
| T-03-17 | D (Denial of service) | Slow API blocks worker pool, fills queue | mitigate | `_MAX_WORKERS = 4` cap (existing); D-07 single-attempt per row prevents retry storms; persistent executor reuses threads |
| T-03-18 | E (Elevation of privilege) | Worker thread accesses Qt widgets directly | mitigate | Worker only emits Signals — all widget mutations happen on main thread via queued slot (Qt thread-safety contract) |
| T-03-19 | T (Tampering) | Race condition: row removed between submit and emit | accept | `update_row_metadata` and `update_row_status` both guard with `if row_id >= self._table.rowCount(): return` — emit on stale row is a no-op, not a crash |
| T-03-20 | D (Denial of service) | Executor leaks threads on window close | mitigate | `closeEvent` calls `self._executor.shutdown(wait=False)` |
</threat_model>
