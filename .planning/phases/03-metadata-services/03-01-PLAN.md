    ```python
    class SpotifyClient:
        """Spotify Web API client using OAuth2 client credentials flow.

        Token is cached in-memory until `expires_in - TTL_BUFFER` seconds elapse.
        No user login — read-only metadata access (META-01).
        """

        TOKEN_URL  = "https://accounts.spotify.com/api/token"
        API_BASE   = "https://api.spotify.com/v1"
        TTL_BUFFER = 60  # seconds before nominal expiry to refresh

        def __init__(self, client_id: str, client_secret: str):
            self._client_id     = client_id
            self._client_secret = client_secret
            self._token:        str | None = None
            self._token_expiry: float      = 0.0

        def _get_token(self) -> str:
            if self._token and time.time() < self._token_expiry:
                return self._token
            credentials = base64.b64encode(
                f"{self._client_id}:{self._client_secret}".encode()
            ).decode()
            resp = requests.post(
                self.TOKEN_URL,
                headers={"Authorization": f"Basic {credentials}"},
                data={"grant_type": "client_credentials"},
            )
            resp.raise_for_status()
            payload = resp.json()
            self._token        = payload["access_token"]
            self._token_expiry = time.time() + payload["expires_in"] - self.TTL_BUFFER
            return self._token

        def get_track_metadata(self, track_id: str) -> dict:
            token = self._get_token()
            resp = requests.get(
                f"{self.API_BASE}/tracks/{track_id}",
                headers={"Authorization": f"Bearer {token}"},
            )
            resp.raise_for_status()
            data = resp.json()
            return {
                "artist":       data["artists"][0]["name"],
                "title":        data["name"],
                "album":        data["album"]["name"],
                "release_type": data["album"]["album_type"],
            }

        def get_album_metadata(self, album_id: str) -> dict:
            token = self._get_token()
            resp = requests.get(
                f"{self.API_BASE}/albums/{album_id}",
                headers={"Authorization": f"Bearer {token}"},
            )
            resp.raise_for_status()
            data = resp.json()
            return {
                "artist":       data["artists"][0]["name"],
                "album":        data["name"],
                "release_type": data["album_type"],
            }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User filesystem → app | `.env` file read at startup; values originate from user dashboards (trusted source) |
| App → Spotify accounts.spotify.com | OAuth2 token exchange over HTTPS — Basic auth header carries base64(client_id:client_secret) |
| App → Spotify api.spotify.com | Bearer-token authenticated GET requests for track/album metadata over HTTPS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | I (Information disclosure) | `.env` containing SPOTIFY_CLIENT_ID/SECRET committed to git | mitigate | Task 1 adds `.env` to `.gitignore` and creates `.env.example` template (only example, no real secrets) |
| T-03-02 | I (Information disclosure) | Token value leaked via logs / status bar / exception trace | mitigate | Never include `self._token` in any user-visible message; `raise_for_status()` exceptions intentionally do NOT carry payload body |
| T-03-03 | S (Spoofing) | `expires_in` from response controls token TTL | accept | Low risk — affects refresh cadence only, never grants extra privileges; `raise_for_status()` rejects HTTP-error responses before expiry parsing |
| T-03-04 | T (Tampering) | Attacker-controlled track_id reaches `https://api.spotify.com/v1/tracks/{id}` URL | mitigate | Plan 03 owns ID extraction via `_SPOTIFY_RESOURCE_RE` regex limiting IDs to `[A-Za-z0-9]+` — no path traversal possible. Plan 01 simply trusts the validated string passed in. |
| T-03-05 | D (Denial of service) | Network timeout on token endpoint blocks worker thread | accept | Phase 3 scope per CONTEXT.md "Claude's Discretion" — single attempt is fine; failure surfaces as `Failed — metadata` per D-07 (Plan 04 owns the failure path) |
</threat_model>
