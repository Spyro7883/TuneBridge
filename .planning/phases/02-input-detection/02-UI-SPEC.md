## Spacing Scale

Tkinter uses integer pixel values. Declared values follow the 4-point grid:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inner widget padding (padx/pady inside Text widget) |
| sm | 8px | Widget-to-edge pad (padx=8 on Text widget, pady on buttons) |
| md | 16px | Frame-to-window edge (padx=20 approximated; padx=16 for inner) |
| lg | 24px | — |
| xl | 32px | — |

Exceptions:
- `input_frame` padx=20 (matches title label padx — inherited from Phase 1 layout, not on grid)
- `input_frame` height=80px (functional requirement — 4-line Text at rowheight ~18px + padding)
- Treeview rowheight=28px (Phase 1 established — must not change)

## Color

| Role | Hex | Usage |
|------|-----|-------|
| Dominant (60%) | `#121212` | Window bg, all TFrame bg, Treeview bg, Text widget bg |
| Secondary (30%) | `#1A1A1A` | Card.TFrame, Treeview.Heading bg |
| Accent (10%) | `#1DB954` | Spotify badge foreground, Done status, selection bg, title label |
| Destructive / error | `#EF4444` | YouTube badge foreground, Invalid URL badge, Failed status |
| Warning | `#F59E0B` | "Awaiting folder" status — Phase 1 established |
| Primary text | `#FFFFFF` | Active row foreground, Text widget fg (active state), cursor |
| Dim text | `#B3B3B3` | Queued row foreground, column headings, status bar, scrollbar arrow |
| Placeholder text | `#555555` | Text widget fg when placeholder is active |
| Text cursor | `#FFFFFF` | `insertbackground` on tk.Text widget |

Accent (`#1DB954`) reserved for: Spotify type badge, Done status row, Treeview selection highlight, title label. Not used on buttons, borders, or decorative elements.

Destructive (`#EF4444`) reserved for: YouTube type badge, Invalid URL type badge, Failed status row. Shared color is intentional — semantic tags differ (`youtube` vs `error` vs `failed`).

Source: Phase 1 `_TAG_COLORS`, `_setup_styles()` — extended here, not changed.

## Components

### 1. InputPasteArea — `tk.Text` widget

Replaces the Phase 1 `_demo_btn` inside `self.input_frame`. The "Start Demo" button is removed.

**Widget constructor:**
```python
self._paste_box = tk.Text(
    self.input_frame,
    height=4,               # ~80px at default line height
    bg="#121212",
    fg="#555555",           # placeholder color on init
    insertbackground="#FFFFFF",
    relief="flat",
    font=("Segoe UI", 10),
    padx=8,
    pady=6,
    wrap="word",
)
```

**Frame adjustment required:**
- Remove `self.input_frame.pack_propagate(False)` from `_build_layout()`
- OR change `height=60` to `height=80` on `self.input_frame`
- Preferred: remove `pack_propagate(False)` — lets Text widget determine frame height naturally

**Pack call:**
```python
self._paste_box.pack(fill="x", expand=True, padx=0, pady=0)
```

**State tracked on app instance:**
```python
self._placeholder_active: bool = True
```

### 3. TypeBadge — Treeview tag configuration

New tags added to `BatchTable._TAG_COLORS`:

```python
_TAG_COLORS = {
    # Phase 1 (unchanged)
    "queued":  {"foreground": "#B3B3B3"},
    "active":  {"foreground": "#FFFFFF"},
    "waiting": {"foreground": "#F59E0B"},
    "done":    {"foreground": "#1DB954"},
    "failed":  {"foreground": "#EF4444"},
    # Phase 2 additions
    "spotify": {"foreground": "#1DB954"},
    "youtube": {"foreground": "#EF4444"},
    "error":   {"foreground": "#EF4444"},
}
```

**Tag order rule (critical):** Type tag must be placed **last** in the tags tuple so it wins the foreground color contest. Status tag first, type tag last:
```python
tags=("queued", "spotify")   # spotify fg wins → #1DB954
tags=("queued", "youtube")   # youtube fg wins → #EF4444
tags=("queued", "error")     # error fg wins   → #EF4444
```

**Type column display values** (what `tree.set(iid, "type")` returns):

| URL classification | Column text | Tag name |
|-------------------|-------------|----------|
| Spotify URL | `"Spotify"` | `"spotify"` |
| YouTube URL | `"YouTube"` | `"youtube"` |
| Invalid/unrecognized | `"Invalid URL"` | `"error"` |

---

### 4. ErrorRowState — invalid URL row

Both columns set simultaneously when a URL fails classification:

| Column | Value | Tag |
|--------|-------|-----|
| `type` | `"Invalid URL"` | `"error"` (foreground `#EF4444`) |
| `status` | `"Skipped — bad URL"` | `"error"` (foreground `#EF4444`) |

The row remains visible. No other rows are affected. No dialog or popup is shown.

**Tag tuple for error rows:** `tags=("error", "error")` — redundant but consistent with the two-tag pattern. Both positions use the same tag name; foreground result is `#EF4444`.

---

### 5. BatchTable._type_tags — tag persistence dict

Required to prevent `update_row_status` from wiping the type tag on future status updates (Phase 3+):

```python
self._type_tags: dict[str, str] = {}   # iid -> type tag name ("spotify"/"youtube"/"error")
```

`add_row()` populates `_type_tags[iid]` at insert time.
`update_row_status()` reads `_type_tags[iid]` and combines: `tags=(status_tag, type_tag)`.

This is a backward-compatible change. Phase 1 tests that assert `tags == ("done",)` must be updated to `tags == ("done", type_tag)` or relaxed to check tag membership.

## Interaction Contracts

### Paste event sequence

1. User pastes (Ctrl+V or right-click Paste) into `_paste_box`
2. `<<Paste>>` fires **before** default insertion
3. Handler reads clipboard directly: `raw = self.clipboard_get()`
4. Handler returns `'break'` — suppresses default text insertion into widget
5. `_placeholder_active` set to `False`, widget fg set to `#FFFFFF`
6. `_process_urls(raw)` called synchronously:
   a. Split by `\n`
   b. Strip each line
   c. Skip blank lines
   d. Classify each non-blank line via `classify_url()`
   e. Call `self.table.add_row()` for each URL (valid or invalid)
7. Placeholder restored: insert placeholder text, set fg to `#555555`, set `_placeholder_active = True`
8. Widget is empty again (paste suppressed) — ready for next paste

**Empty clipboard guard:** Wrap `clipboard_get()` in `try/except tk.TclError: return 'break'`.

### FocusIn behavior

If `_placeholder_active is True`:
- Delete widget content
- Set fg to `#FFFFFF`
- Set `_placeholder_active = False`

### FocusOut behavior

If `_paste_box.get("1.0", "end-1c").strip() == ""`:
- Insert placeholder text
- Set fg to `#555555`
- Set `_placeholder_active = True`

### Classification logic

```
classify_url(url: str) -> str | None
  SPOTIFY_RE = r'open\.spotify\.com/(track|album|playlist|artist)/'
  YOUTUBE_RE = r'(youtube\.com/watch\?.*v=|youtu\.be/)'
  returns "Spotify" | "YouTube" | None
```

`None` result → invalid row. Must be exposed as a module-level importable function (not a method) to enable pure unit tests without tkinter fixture.

### Status bar update on paste

After `_process_urls` completes, update `self._status_var`:
- Mixed or valid batch: `"N URL(s) added — paste more or start processing"`
- All invalid: `"No valid URLs found — check your links"`
- Count excludes invalid rows from the "added" phrasing

## Phase 3 Interface Contract (informational — for planner)

Phase 2 exposes these data access points for Phase 3:

| Data | Location | Access method |
|------|----------|---------------|
| Row iid | returned by `add_row()` | store in `self._pending_iids: list[str]` on app |
| URL string | `table._rows[iid]` | direct dict access |
